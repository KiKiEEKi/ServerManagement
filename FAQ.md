<details>
  <summary><b>🇬🇧 EN | Example of adding a new command</b></summary>
  <br>

  Create 3 new input fields for the details:
  ```bash
  sm_addvip <#steam_id|#name|#userid> <group> <duration>
  ```

  Create 3 new fields where the "VIP" group and a 1-day duration are already pre-filled:
  ```bash
  sm_addvip <#steam_id|#name|#userid> "VIP" "86400"
  ```

 💡 **Tip:**
  * Items in `< >` represent input fields.
  * Items in `" "` are pre-filled values that appear when the command is selected.
</details>

<details>
  <summary><b>🇷🇺 RU | Пример добавления новых команд</b></summary>
  <br>

  Создадутся 3 новых поля для ввода значений:
  ```bash
  sm_addvip <#steam_id|#name|#userid> <group> <time>
  ```

  Создадутся 3 новых поля, но в них уже будет прописана группа "VIP" и время выдачи 1 день:
  ```bash
  sm_addvip <#steam_id|#name|#userid> "VIP" "86400"
  ```

 💡 **Подсказка:**
  * Все, что в `< >` — это будет описание для ввода.
  * Все, что в `" "` — будет уже автоматически прописано при выборе команды.
</details>
